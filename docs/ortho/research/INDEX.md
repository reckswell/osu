## Cross-game topics

| Topic | Question to answer | Note | Status |
|---|---|---|---|
| Speed under perspective | How do perspective games define and display speed so it feels constant? All define it in track space (visible time, units/s, beats) and never correct for the camera; near-line speed is 1/r track heights per visible time (Chunithm 4.2×, USC 9.4× flat); the Sonolus Sekai engine alone uses an exponential approach (line/far 14× instead of 189×) | `topic-speed.md` | draft |
| Covers and walls | Every cover/wall option across games, with defaults and adjustment UX. Only IIDX FHS and beatoraja keep visible time when the cover moves; Chunithm, Quaver, Etterna, mania, USC, Sekai (Sonolus) keep speed. Mid-song adjustment only in IIDX, beatoraja, Etterna (customise mode); steps from 0.1% (beatoraja) to 5.8% (Chunithm) | `topic-covers.md` | draft |
| Wide key counts | How 7K-10K stays readable on a tilted track (any game that does it). Chunithm (16 cells) and YARG (10 white keys) keep one width and camera, like us; readability comes from a coarser group tier (Chunithm's default 4-split, YARG half-octave tints, SM5 kb7 gaps), adjacent lanes never alike, notes filling 98-100% of the lane, and hiding the far end (wall, fade). At 1080p our Chunithm 10K lanes (117 → 28 px) beat Chunithm's 1-cell lanes (73 → 17.6); Voltex 10K (84 → 9 px) is below every reference | `topic-wide-keys.md` | draft |
| Off-centre fields | Where off-centre fields sit and where their perspective converges. Placement by side (IIDX, beatoraja 1P 0.168W, SM5 P1 0.283W) or setting (DJMAX/Bemuse Left/Center/Right, Quaver `ColumnAlignment`, Etterna drag per key mode); Etterna and Bemuse default centred. Perspective on a side field is rare: SM skew 0 keeps the vanishing point over the field (lean ≤ 0.8°), skew 1 / Etterna dragged field / YARG multiplayer (default 9.7°) / Rock Band lean it towards the screen centre; none pins the line (SM drifts 0.1-1.7% W, YARG 1.7-5.7% W). Too wide: SM re-centres then shrinks, YARG caps width; nobody slides sideways. Proposes: keep the skin's centre, vanishing point over the track (k = 0) with screen-centre and halfway options to show Alpha, shrink instead of clamp | `topic-off-centre-fields.md` | draft |
